# src —— 源码留档与后续构建入口

M1 阶段采用**零构建**方案：`client.js` 是手写维护的浏览器闭包工厂（与官方 decoration 模板一致），
可以直接被 DSH 客户端加载器消费，不需要 TypeScript、打包器或 CSS 管线。

`src/` 目录当前用于：

- 记录皮肤设计稿与共享逻辑的**可读源码**（后续引入构建时迁入）；
- 为 M2「皮肤包开放格式」预留模块划分（`skins/`）。

## 约定

- 运行时唯一入口仍是仓库根目录的 `client.js`；
- 皮肤定义在 M1 内联于 `client.js`，M2 抽到 `src/skins/*.js` 并通过构建产物合并；
- 任何新增样式都必须挂在 `html[data-dsh-bubble-skin="<id>"]` 作用域下。
