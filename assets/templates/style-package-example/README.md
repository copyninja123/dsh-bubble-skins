# 内部素材包示例：固定气泡样式

> 本目录是 `docs/BUBBLE_SPEC.md` v3.1 的**格式示例**，不是正式发布素材。
> 演示「DSH 基准背景 + 可选挂件拆分 + manifest 组装 + 整体效果图」的完整结构。

## 结构

```
style-package-example/
├── manifest.json          # 样式参数
├── background.svg         # 九宫格背景（运行时）
├── accessories/           # 可选挂件（运行时）
│   └── tl-star@2x.svg
├── preview.svg            # 预览源（不发布）
├── preview.png            # 整体效果图（文档/验收）
└── README.md
```

## 示例参数

| 项 | 值 | 说明 |
| --- | --- | --- |
| 画布 | **1050×84 @2x** | 对应 525×42 逻辑尺寸（DSH 原版气泡） |
| `slice` | `[24, 32, 24, 32]` | 源图像素：上/右/下/左 |
| `borderWidth` | `[10, 16, 10, 16]` | CSS px；上下 10 对应 DSH 内边距 |
| `padding` | `[10, 16, 10, 16]` | 文字内边距；单行总高 42px |
| 文字色 | `#ffffff` | 深色背景 |
| 尾巴色 | `#12345F` | 独立尾巴 |
| 挂件 | 左上星标 24×24 | 独立组装，固定尺寸 |

## 注意

- 真实固定样式请另建 `assets/styles/<id>/`，不要把示例当发布素材；
- `preview.png` 仅用于展示/验收，运行时不读取；
- 有真实边框的样式才允许气泡整体加高；装饰本身不把气泡撑高；
- 素材必须原创或确认授权，避免第三方版权素材进入 MIT 仓库。
