## 尺寸与参数

| 项目 | 值 |
| --- | --- |
| 逻辑基准 / 源图 | 525×42 / 1050×84 @2x |
| slice（源图单位，上右下左） | [28,44,28,44] |
| borderWidth / borderImageWidth（CSS px） | [14,22,14,22] |
| padding（CSS px） | [10,16,10,16] |
| textColor / textShadow | #244B30 / none |
| tailColor | #F2F8EA |
| accessories | [] |

使用14px字体、22px行高，上下padding均为10px，因此单行42px、两行64px、三行86px；不通过裁切、缩放正文或装饰额外增高。宽度随内容变化，最大约525px。

为避免单字气泡的伪元素边框绘制溢出，将左右切片/显示宽度调整为44/22；上下28/14。明确叶草落在固定角内，连续草坡与背景允许自然拉伸。文字允许覆盖叶草与薄草坡，未为装饰增加文字高度。

## 验收证据

- Chrome实测源图1050×84、预览1050×84；单字、emoji单行42px，两行64px，三行86px；长英文与10行正文无横向溢出。
- 实测单字外宽46px，未强制拉成525px；预览展示最大宽单行仅供标准验收。
- 已检查普通短/长/多行及明暗环境截图；固定叶草和连续草坡位置正常。
- 以实际每行文字Range矩形取样，保持布局与全部装饰不变，仅隐藏字形，遍历文字覆盖范围内所有背景像素，得到保守最低对比度约6.08:1，达到4.5:1。不是只测源图中央空白或平均色。矩形包含字间空白，因此属于保守检查。
- 136552个背景像素取样，覆盖浅色/深色、普通短消息、最大宽单行、多行。最差背景RGB为[184,212,152]。
- 本轮使用2个子代理：草坡独立设计、v3.2验收规范复核；主代理修正短消息切片溢出，完成锦鲤设计与实际组装检查。
- 已接入插件运行时（新素材已内联 client.js）；DSH 真机仍待验收，附件、引用、pending、回声及宿主CSS待验证。
